# Biblioteca de skills para jogos

Este repositório reúne 75 skills em `skills/`, os 25 pacotes ZIP originais em `pacotes/` e uma skill de aprimoramento de jogos em `gemini/SKILL.md`.

As skills incluem seus arquivos auxiliares copiados das instalações locais. Consulte as licenças e origens dos pacotes antes de redistribuí-los. Os ZIPs preservam a organização anterior e sua aceitação por plataformas externas depende da validação dessas plataformas.

A skill para Gemini pode ser fornecida como instrução ou adaptada ao mecanismo de skills disponível no ambiente usado.
